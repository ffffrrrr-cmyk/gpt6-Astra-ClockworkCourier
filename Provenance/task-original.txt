二、玩法目标
制作固定侧视、三维场景的 2.5D 动作探索游戏。玩家操控负责输送能源芯的机械信使，穿过废弃钟楼的齿轮工坊。核心是跳跃、空中冲刺、定时反击与电量取舍，并通过能力解锁返回此前无法到达的支路；不是自动跑酷或只有移动的场景参观。

完整循环：抵达区域 → 观察巡逻和机关周期 → 通过战斗与平台挑战 → 获取电池或永久能力 → 开启捷径与检查点 → 击败守门机械体 → 送达能源芯并结算。设计约 20—30 分钟的完整流程，分成工坊、升降井和钟面核心三段；每段至少包含一个新组合机制。首次通关后保留区域选择和挑战计时。

三、核心实现
1. A/D 或方向键移动，Space 跳跃，Shift 冲刺，J 普通攻击，K 短时格挡，E 交互，Esc 暂停。提供可读键位提示、输入锁定和 UI 焦点管理，避免菜单操作穿透成攻击。
2. 角色采用清楚的地面/空中/攻击/受击/死亡状态。实现可调跳跃高度、短暂离地宽限与跳跃输入缓存，冲刺有冷却且不可无限空中连发。碰撞判定与画面脚部一致，不能穿墙、卡进平台或站在不可行走斜面上。
3. 普攻具有前摇、有效命中和恢复阶段；每次挥击对同一目标只命中一次。格挡成功需落在判定窗口内，成功反馈和失败受伤可区分。受击无敌时间防止同帧连伤，死亡只触发一次。
4. 至少 3 种敌人：地面巡逻近战、远程蓄力炮台、空中轨迹守卫。实现巡逻/发现/追击或瞄准/攻击/受击/死亡状态及攻击预警。末段守门机械体有两阶段和可学习的攻击节奏，不靠堆血量制造难度。
5. 电量用于冲刺强化或格挡资源，恢复点和战斗掉落给予补充；资源耗尽仍能继续基础移动，不得造成无法继续的软锁。中途获得一次永久能力，如二段跳，随后用它开启此前可见支路。
6. 实现移动平台、周期压机、可破坏障碍、两处捷径和检查点。死亡恢复角色、敌人和机关到规定状态，保留已获得永久能力，避免刷奖励或在危险区域复活。移动平台载人时不抖动、不滑穿。
7. 主菜单、教学、生命/电量 HUD、暂停、音量/画质/屏幕震动开关、死亡重试、通关结算、进度保存与重置确认齐全。损坏存档可恢复默认并说明。角色控制、战斗、敌人、机关、关卡、UI 和存档合理分离，内容参数数据化。

使用适合目标设备的 Unity URP，优先本机稳定 LTS，记录完整编辑器和包版本。面向 Windows x64，插件披露用途、版本及许可，优先避免付费和私有依赖。
